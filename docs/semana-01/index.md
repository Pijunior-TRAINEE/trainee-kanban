# Semana 1: Metodologia Ágil e Kanban

Este material foi feito para te dar uma base sólida em Scrum + Kanban sem enrolação. São 5 dias de leitura curta (15 a 20 minutos cada) e, no final, um exercício prático simulando uma situação real com o cliente.

## Como usar

- Um módulo por dia: dá para fazer ao longo de uma semana de trabalho, sem pressa.
- Cada dia constrói em cima do anterior, então vale seguir a ordem.
- No fim da semana tem o **exercício final** (uma simulação de reunião com cliente) e o **gabarito**, para você conferir sua resposta depois de entregar.
- Todo módulo segue o mesmo formato: mapa do conceito, mínimo para começar, desafio aberto, pergunta de pesquisa e entregável documentado.
